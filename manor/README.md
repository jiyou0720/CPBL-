# 저택의 실체 (The Manor)

## 실행 방법
```bash
sudo apt install -y libncurses5-dev locales
sudo locale-gen ko_KR.UTF-8
make && ./manor
```

## 조작키
| 키 | 기능 |
|---|---|
| W/A/S/D | 이동 |
| F | 상호작용 (아이템, 대화, 퍼즐, 핵) |
| E | 인벤토리 |
| N | 일지 보기 |
| M | 저장 (슬롯 1) |
| Q | 아이템 버리기 |
| TAB | 업적 확인 |
| ESC | 일시정지 |

## 맵 기호
- `@` 플레이어  `G` 순찰 귀신  `g` 매복 귀신  `B` 집사(추격)
- `#` 벽  `D` 문  `d` 잠긴 문  `n` 일지  `I` 아이템  `P` 퍼즐
- `K` 열쇠  `v/^` 계단  `*` 핵(붉은 보석)  `C` 집사(평상시)

## 목표
퍼즐 3개를 풀고, **성수** + **망치**를 찾아  
마스터 침실 스위트의 **붉은 보석(핵)**을 파괴하라!
